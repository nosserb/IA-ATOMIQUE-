    ────────────────────────────────────

    Formule:  Speedup_max = 1 / (S + (1-S)/N)
    
    Données:
    - S = 0.3973
    - N = 8
    
    Calcul:
    Speedup_max = 1 / (0.3973 + 0.6027/8)
                = 1 / (0.3973 + 0.0753)
                = 1 / 0.4726
                = 2.12x
    
    Résultat:

3️⃣  Inverse: Trouver S_max pour T_par < 1ms
    ──────────────────────────────────────

    Équation:  1 ms ≥ S·T_seq + (1-S)·T_seq/N
    
    Avec T_seq = 2 ms, N = 8:
    1 ≥ S×2 + (1-S)×2/8
    1 ≥ 2S + 0.25(1-S)
    1 ≥ 2S + 0.25 - 0.25S
    1 ≥ 1.75S + 0.25
    0.75 ≥ 1.75S
    
    S ≤ 0.75/1.75 = 0.4286 (42.86%)
    
    Résultat:
    ✅ S_actuel (39.73%) < S_max (42.86%)
    → <1ms RÉALISABLE avec T_seq ≤ 2 ms et optimisations
