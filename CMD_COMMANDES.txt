📝 COMMANDES À COPIER DANS CMD
===============================

Après avoir téléchargé et extrait ia-atomique-web.zip:

1️⃣ OUVRIR COMMAND PROMPT
Appuie sur: Win+R
Tape: cmd
Clique OK

2️⃣ NAVIGUER AU DOSSIER
Copie-colle cette commande dans CMD:

cd C:\chemin\vers\ia-atomique

(Remplace C:\chemin\vers\ par le vrai chemin)

Par exemple:
cd Downloads\ia-atomique
cd C:\Users\TonNom\Downloads\ia-atomique-web

3️⃣ COMPILER (première fois)

go build -o programme.exe

4️⃣ LANCER LE SERVEUR

programme.exe web

5️⃣ OUVRIR NAVIGATEUR

http://localhost:8080

===============================

COMMANDES RAPIDES À COPIER:

REM Ouvrir le dossier
cd Downloads\ia-atomique-web

REM Compiler
go build -o programme.exe

REM Lancer
programme.exe web

===============================

ALTERNATIVE - AVEC LES SCRIPTS:

Si tu as les fichiers .bat:

REM Installer
install.bat

REM Lancer
run-web.bat

===============================

❓ SI ERREUR "Go is not recognized"

Cela signifie que Go n'est pas installé.

Télécharge depuis: https://golang.org/dl/
Installe le fichier .msi
Redémarre Windows
Réessaye

===============================

✅ VOILÀ!

Le serveur devrait démarrer et tu peux
ouvrir http://localhost:8080 dans le navigateur.

===============================
