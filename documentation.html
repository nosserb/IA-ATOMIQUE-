Language Motor & Semantic Layers

HTML Content Extraction

A specialized 8-step pipeline sanitizes incoming web data. It performs script removal, main content isolation (main, article, div priority), and whitespace normalization for reliable NLP processing.

Layer 1: Concept Extraction

Distills the dominant idea by identifying core thematic clusters and keyword density.

Layer 2: Structural Logic

Classifies sentences into objective Facts, Subjective Interpretations, or Consequences.

Layer 3: Axis Mapping

Categorizes content across 7 semantic dimensions including Pragmatic, Cognitive, and Moral.
